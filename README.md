# Smart Home

A simple Arduino based project built with PlatformIO. The project uses custom NanitLib library.

---

## Features:
* Garage - garage door control 
* Ventilation - gas control
* Security - basic movement detection (keypad, PIR, buzzer)
* Remote Web Control - remote control over the web
* Integrated - all features integrated into the firmware
 
## Getting started:
> 1. git clone https://github.com/Taras-Ivashchuk/smart_home.git
> 2. cd smart_home
> 3. pio run -t upload
